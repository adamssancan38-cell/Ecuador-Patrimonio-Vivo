INSTRUCCIONES PARA EL EQUIPO:
──────────────────────────────
1. Coloca aquí las fotografías de cada lugar turístico.
2. Usa nombres de archivo en minúsculas, sin espacios ni tildes.
   Ejemplo: cotopaxi.jpg, otavalo.jpg, galapagos-santa-cruz.jpg

3. En js/data.js, busca el lugar correspondiente y completa:
      imagen:        "img/nombre-del-archivo.jpg"
      creditoImagen: "Nombre del fotógrafo / Fuente"
      licencia:      "CC BY 4.0 / Dominio público / etc."

4. Formatos recomendados: JPG o WebP
5. Tamaño recomendado: 1200×800 px como mínimo, optimizadas para web.
   Puedes usar squoosh.app para comprimir sin perder calidad.
